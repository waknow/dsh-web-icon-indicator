活动 Agent 数（角标数字）

数字如何呈现由下方「提示通道」决定：标题数字 / 底部圆点 / 底部数字胶囊 / 数字角标（对比基准）；活动数变化时数字会 pop 缩放弹出（借鉴 favico.js 的入场动画）。

提示通道（视觉方案对比）

满幅数字（Gmail 未读式）：≥2 个活动 agent 时整帧为状态色数字块（不画鲸鱼，pop 切换数字不穿帮），数字约占图标高度的 31%-52%，16px 与固定标签页都可读；0–1 个时回到鲸鱼（门槛与插件 BIG_NUM_MIN=2 一致）。本 demo 的浏览器标签 favicon 会实时演示。
